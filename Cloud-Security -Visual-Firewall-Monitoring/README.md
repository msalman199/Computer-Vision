## 📖 Overview

> 💻 **Lab Environment:** Local machine only — no cloud services required.

This lab builds a foundation in using visual tools to monitor and secure network activity. You capture real network traffic, convert it into structured data, visualize network behavior, flag abnormal patterns with Python, and simulate firewall-level anomaly detection — all offline.

## 🧠 Key Concepts

| Concept | Description |
|---------|-------------|
| **Wireshark** | GUI-based network protocol analyzer used to capture traffic |
| **tshark** | Command-line counterpart to Wireshark for capturing and processing traffic |
| **`.pcapng`** | Packet capture file format produced by Wireshark/tshark |
| **Structured CSV Conversion** | Turning raw packet captures into tabular data for analysis |
| **Traffic Visualization** | Plotting network behavior with Python to make patterns visible |
| **Anomaly Flagging** | Identifying abnormal traffic patterns in the data |
| **Firewall-Level Anomaly Detection** | Simulated detection of unusual network activity, performed offline |
