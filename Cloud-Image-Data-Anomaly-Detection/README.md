## 🔭 Overview

> 🖥️ **Lab Environment:** Ubuntu system with MinIO, Python, and OpenCV. Everything runs fully offline.

This lab combines cloud storage with computer vision. You set up MinIO to simulate cloud storage for images, upload and access image datasets as if working with AWS S3, and use OpenCV histogram comparison to detect anomalies based on similarity scores.

| 🎯 Learning Objective | 🛠️ Skill Practiced |
|---|---|
| Simulate cloud storage | MinIO setup |
| Work with image datasets in storage | Uploading and accessing images, S3-style |
| Detect anomalies in images | OpenCV histogram comparison and similarity scores |

## 📚 Key Concepts

| 💡 Concept | 📖 Description |
|---|---|
| **MinIO** | Local object storage used to simulate cloud storage |
| **AWS S3-Style Storage** | Storing and accessing datasets as objects, as you would on AWS S3 |
| **OpenCV** | Open-source computer vision library used from Python for image processing |
| **Histogram Comparison** | Comparing the histograms of images to measure how similar they are |
| **Similarity Scores** | Values used to flag images that deviate from what is expected as anomalies |
| **Anomaly Detection** | Identifying images that differ significantly from the rest |
