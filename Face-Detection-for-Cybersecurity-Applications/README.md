## 🔭 Overview

> 🖥️ **Lab Environment:** Ubuntu machine with Python and OpenCV. Everything runs offline.

This lab walks you through building a working local face detection system. You start by detecting faces in a static image using Haar cascades, then extend the solution to real-time detection through a webcam.

| 🎯 Learning Objective | 🛠️ Skill Practiced |
|---|---|
| Detect faces in a static image | Haar cascade classifiers |
| Detect faces in real time | Webcam-based face detection |
| Build a local detection system | Offline face detection for cybersecurity use cases |
