## 📖 Overview

> 💻 **Lab Environment:** Ubuntu system, local machine only — no internet or cloud services required.

This lab demonstrates how **Optical Character Recognition (OCR)** can be used to automate log analysis. Using Tesseract OCR on Ubuntu, you extract text from log screenshots and flag error-related keywords for quick diagnostics — improving visibility into system operations using only your local machine.

## 🧠 Key Concepts

| Concept | Description |
|---------|-------------|
| **OCR (Optical Character Recognition)** | Technology that converts text in images into machine-readable text |
| **Tesseract OCR** | The OCR engine installed and configured on Ubuntu in this lab |
| **Screenshot Log Extraction** | Pulling log text out of screenshot images rather than log files |
| **Keyword Flagging** | Marking error-related keywords in extracted text for quick diagnostics |
| **Offline Analysis** | Performing the entire workflow on a local machine without external services |

## 🌍 Real-World Applications

- 🔧 **Automated log analysis** — Extract and review log text from screenshots when raw log files are unavailable
- 🚨 **Quick diagnostics** — Flag error-related keywords to speed up troubleshooting
- 👁️ **Operational visibility** — Improve insight into system operations using local tooling
- 🔒 **Offline workflows** — Analyze logs entirely on your own machine
