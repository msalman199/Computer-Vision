## 🔭 Overview

> 🖥️ **Lab Environment:** Ubuntu machine with Python and OpenCV. No cloud services are required — everything runs locally.

This lab introduces the core computer vision workflow using **OpenCV**. You install the library on Ubuntu, work with images in Python, and apply two foundational transformations: grayscale conversion and resizing.

| 🎯 Learning Objective | 🛠️ Skill Practiced |
|---|---|
| Install and configure OpenCV | Environment setup on Ubuntu |
| Load, display, and save images | Image I/O with Python |
| Convert images to grayscale | Basic color-space transformation |
| Resize images | Basic geometric transformation |

## 📚 Key Concepts

| 💡 Concept | 📖 Description |
|---|---|
| **OpenCV** | Open-source computer vision library used from Python for image and video processing |
| **Image Loading** | Reading an image file from disk into memory as an array |
| **Image Display** | Showing a loaded image in a window for visual inspection |
| **Image Saving** | Writing a processed image back to disk |
| **Grayscale Conversion** | Reducing a color image to a single intensity channel |
| **Image Resizing** | Changing an image's dimensions (width and height) |
