## 🔭 Overview

> 🖥️ **Lab Environment:** Ubuntu-based development environment with Jenkins and Selenium. Everything runs offline.

This lab simulates a real-world DevOps pipeline with visual testing. You build a local CI/CD pipeline with Jenkins, integrate Selenium to perform visual checks on a web application, and capture and save screenshots as part of automated QA.

| 🎯 Learning Objective | 🛠️ Skill Practiced |
|---|---|
| Build a local CI/CD pipeline | Jenkins pipeline setup |
| Perform visual checks on a web application | Selenium integration |
| Automate QA evidence | Capturing and saving screenshots |
