## 🔭 Overview

> 🖥️ **Lab Environment:** Ubuntu machine with Python and OpenCV. Everything runs fully offline.

This lab introduces the foundations of iris recognition. You capture high-resolution eye images from a webcam, isolate the iris using Hough Circle detection and preprocessing, and extract features with a simple histogram-based method for biometric comparison.

| 🎯 Learning Objective | 🛠️ Skill Practiced |
|---|---|
| Capture eye images | High-resolution webcam capture |
| Isolate the iris | Preprocessing and Hough Circle detection |
| Extract biometric features | Histogram-based feature extraction |

## 📚 Key Concepts

| 💡 Concept | 📖 Description |
|---|---|
| **Iris Recognition** | Biometric approach that identifies individuals using features of the iris |
| **Image Preprocessing** | Preparing eye images so the iris can be detected reliably |
| **Hough Circle Detection** | Technique for detecting circular shapes, used here to isolate the iris |
| **Histogram-Based Feature Extraction** | Simple method for representing the iris as features for biometric comparison |
| **Biometric Comparison** | Comparing extracted features to evaluate whether they match |
